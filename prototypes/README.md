# Prototypes

This directory holds throwaway design prototypes. They are not production code. Each one exists to settle one design decision, and the real build follows from that decision in the main source tree.

| File | Decision it settles |
|---|---|
| `org-chart.html` | Which layout shows the agent society's hierarchy and reporting lines best in the Operator's Org view. Open it in a browser and press 1, 2, or 3 to switch layouts. All Agent data in it is sample data. |
